# Correspondencia con las condiciones de entrega

El archivo para entregar es `Midterm1_ID.pdf`. Los identificadores deben sustituirse por los de los autores. Incluye Adrian Compean Sepúlveda, Daniel Camacho Contreras, Luis Contla Ramírez y Rodrigo Cortés Pacheco.

| Condición | Ubicación en el informe y evidencia |
| --- | --- |
| Un PDF IEEE en dos columnas | Clase IEEEtran, modo conference, 10 puntos; fuentes en `report/paper/` |
| Máximo cuatro páginas de cuerpo | Tres páginas de cuerpo y una página adicional de referencias y apéndices |
| Q1 definición formal y motivación | Entradas, salidas, objetivo, restricciones, modelo P prec Cmax, supuestos y NP-dificultad |
| Q2 algoritmo y corrección | Pseudocódigo, invariantes, seguridad, terminación y contribución delimitada |
| Q3 complejidad y garantías | Tiempo, espacio, preguntas cuadráticas, mensajes, cota clásica condicionada y overhead |
| Q4 robustez y alternativas | Baseline secuencial, FIFO, prioridad crítica, fallos y métricas de calidad |
| Q5 siguientes pasos | Costos condicionados, inferencia selectiva, admisión y recuperación; evaluación de cada mejora |
| Panorama | Caso real, arquitectura, restricciones y calidad de la respuesta |
| M1 implementación | Código ejecutado, MPI y MCP reales, comparación empírica y recursos observados |
| M2 reproducibilidad | Tres consultas con referencias, tolerancia 1e-9, 27 ensayos de calidad y 54 ejecuciones totales |
| Variabilidad de LLM | Se distingue ausencia de LLM en mediciones de evaluación Jev autenticada pendiente |
| M3 planeación | Objetivos medibles, selección de workers y umbrales de calidad |
| M4 planeación | Comparadores clásicos, diseño de benchmark y cinco dimensiones requeridas |
| Repositorio y hoja de ruta | Implementado, diseñado y pendiente; scripts y resultados entregados |
| Evidencia y citas | Referencias académicas de Kahn, Graham y HEFT, y documentación primaria de MPI, MCP y Jev |

La comparación con algoritmos específicos vistos en clase debe cotejarse con el temario; se seleccionaron Kahn, list scheduling, FIFO y camino crítico. HEFT se propone como extensión, sin afirmar que ya fue implementado. La consulta autenticada a Jev requiere una clave y no se presenta como ejecutada. La validación multinodo y Docker también están identificadas como pendientes.
